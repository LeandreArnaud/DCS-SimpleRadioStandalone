SRS can be setup to look to DCS for the aircraft type you are in and apply a profile accordingly.

For this to work a profile needs to be created for each aircraft you'd like to customize SRS for, and for any aircraft you don't have a profile for the default profile will be used.

For this to work the option 'Settings' > 'Global Settings' > 'Auto Select Profile For Aircraft' must be enabled.  
Fore information on the settings page [here](https://github.com/ciribob/DCS-SimpleRadioStandalone/wiki/Settings).

*Hint - If you have some common settings you prefer across all profiles set these first and save them in the default profile, then when creating new profiles use the 'copy profile' option with the default profile selected to create a new profile whilst inheriting your favourite defaults.

For automatic per aircraft profiles to work the profiles need to be named per the aircraft name from the in game scoreboard.  
The first few characters are enough, symbols and spaces are ignored.  
For example, if you want the same settings for the F-14A and F-14B, then one profile named F14 will be fine.  
If you want different settings for the 2 variations you must use the full name of the aircraft, eg: F14A and F14B

This applies to all aircraft that have variations.  
Remember case, symbols and spaces are ignored.
